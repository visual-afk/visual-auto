# 카드뉴스 컨셉 — 트리필드 (머리카락 권위자, 통통 튀게)

## 한 줄 컨셉
**머리카락에 관한 모든 궁금증의 종결자.** 근데 딱딱한 교수님이 아니라, 옆자리에서 "그거 진짜 궁금했지?" 하고 신나서 풀어주는 **똑똑하고 유쾌한 친구.**

## 타겟
머리카락·두피·헤어케어가 궁금한 모든 사람. 특히 "이거 나만 궁금한가?" 싶은 짜치는(사소하지만 계속 신경 쓰이는) 질문을 가진 사람들.

## 카드 톤·문법
- **통통 튀게.** 리듬감 있는 짧은 문장. 반전·유머 한 스푼.
- 궁금증을 질문으로 던지고 시원하게 답한다. 권위는 있되 잘난 척하지 않는다.
- 전문 용어는 쓰되 바로 쉬운 말로 번역한다. ("모발 큐티클(=머리카락 겉비늘)")
- 이모지는 카드 디자인이 대신하므로 텍스트엔 안 쓴다. 대신 **말맛**으로 튄다.

## 훅 방식 (표지) — 짜치는 궁금증 시리즈
사람들이 검색은 안 해도 계속 궁금해하는 걸 대놓고 건드린다.
- 예: "머리 감고 자면 진짜 탈모 와요?" / "정수리만 왜 이렇게 떡져요?" / "새치, 뽑으면 두 개 나요?"

## 콘텐츠 문법 (포인트 카드)
- 카드 하나 = 궁금증 하나 또는 반전 사실 하나.
- "사실은요…" "반전:" "결론부터:" 같은 리듬 장치로 스크롤을 끈다.
- 근거는 짧게, 단정은 확실하게. "저장각" "친구한테 보내주기" 나오게.

## CTA 방식
미디엄. 다음 궁금증을 예고하거나, 시리즈 팔로우를 부른다.
- 예: "다음 편: 린스 vs 트리트먼트 진짜 차이" · 배지: "머리카락 궁금증 → 팔로우 ↓"

## 하지 말 것
- 지루한 백과사전식 나열. 재미 없으면 트리필드가 아니다.
- 근거 없는 낚시. 통통 튀되 틀리면 권위가 무너진다.
- 럭셔리·절제 톤(그건 비주얼살롱/아카데미). 여긴 활기와 재미가 무기다.
