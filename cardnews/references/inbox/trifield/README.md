# 트리필드 레퍼런스 인박스 — 예진매니저용

여기에 트리필드 카드뉴스의 재료가 될 **타 업종 레퍼런스**를 넣어주세요.
업종은 아무거나 괜찮아요 (경제·과학·요리·운동·심리·IT…). "구조가 좋은 것"이 기준입니다 — 내용은 시스템이 모발 과학으로 바꿉니다.

## 넣는 법

1. 카드뉴스 이미지들을 폴더 하나로 묶기: `2026-08-19-복리의마법/01.jpg, 02.jpg, …`
2. 같은 폴더에 `meta.md` 하나 (아래 3필드만 채우면 끝):

```markdown
source: 인스타 @계정명 또는 URL
industry: 경제        # 경제/과학/요리/운동/심리/패션/IT/기타
why: 6번째 장에서 반전 터뜨리는 리듬이 좋았음   # 왜 좋았는지 한 줄
```

## 어떤 레퍼런스가 좋은가 (트리필드 기준)

- ✅ 숫자 하나로 멈춰 세우는 표지 / 오해를 깨는 구성 / "저장각" 요약 카드가 있는 것
- ✅ 어려운 개념을 웃긴 비유로 푸는 것 (트리필드의 낙차 리듬과 궁합 최고)
- ❌ 예쁘기만 하고 정보 구조가 없는 것 — 디자인(컬러·폰트)은 어차피 버립니다
- ❌ 스타일/패션 화보형 — 그건 살롱 인박스로

## 이후 흐름 (자동)

3회 사용된 레퍼런스는 `cardnews/references/retired/`로 이동합니다.
