# 02-트리필드. 레퍼런스 → 트리필드 치환 엔진

> 예진 매니저가 넣은 **타 업종 카드뉴스 레퍼런스**를 트리필드(모발 과학·키치) 주제로 바꾸는 규칙.
> 입력: `cardnews/references/dna/{id}.json` (해부 완료된 reference_dna) · 출력: 트리필드 토픽 후보 3개 + 선택된 1개의 `cardnews_plan.json` 골격.
> 공통 해부 절차(이미지→DNA)는 02 공통 문서 소관. 이 문서는 **트리필드로 트는 단계 [3]만** 다룬다.

---

## 0. 대원칙 (P1 재확인)

레퍼런스에서 가져오는 것 / 버리는 것:

| 가져온다 (구조와 리듬) | 버린다 (디자인 값·소재) |
|---|---|
| 장수, 카드 역할 시퀀스 | 컬러, 폰트, 로고, 사진, 일러스트 톤 |
| 후킹 공식 (어떻게 멈춰 세웠나) | 원업종의 고유명사·수치 (치환 대상) |
| 정보 밀도 (카드당 정보 몇 개) | 말투 (트리필드 톤으로 교체) |
| 강조 리듬 (몇 번째 카드에서 터뜨리나) | CTA 목적지 |

## 1. 도메인 라우팅 사전 (타 업종 → 모발 과학)

레퍼런스의 업종(`dna.industry`)을 보고 아래 사전으로 **개념 단위 매핑**을 찾는다. 매핑은 "단어 바꿔치기"가 아니라 **정보 구조가 같은 모발 현상 찾기**다.

### 경제·재테크 → 손상 누적과 케어 루틴
| 원개념 | 트리필드 대응 | 왜 구조가 같은가 |
|---|---|---|
| 복리 | 손상 누적 (열·마찰의 복리) / 케어 루틴의 복리 효과 | 작은 것이 시간에 걸쳐 기하급수로 |
| 원금 손실 | 시스틴 결합 파괴 (비가역) | 한번 잃으면 복구 불가 |
| 분산 투자 | 케어 루틴 분산 (세정·보습·단백질 밸런스) | 한 곳에 몰빵하면 리스크 |
| 사채 이자 | 매일 고데기 = 고금리 대출 | 편리함의 대가가 뒤에 온다 |
| 절세 | 손상 예방 (보수보다 예방이 싸다) | 나가기 전에 막는 게 이득 |

### 과학·우주·자연 → 그대로 직결 (최고 궁합)
| 원개념 | 트리필드 대응 |
|---|---|
| 물질의 구조·단면 | 모발 3층 구조 (큐티클/코르텍스/메두라) |
| 화학 반응·결합 | 펌·염색의 결합 화학 (수소/이온/시스틴) |
| 온도·상태 변화 | 열 변성 (계란 익듯 단백질이 굳는다) |
| 생태·주기 | 모발 성장 주기 (성장기→퇴행기→휴지기) |

### 요리·식품 → 단백질과 pH
| 원개념 | 트리필드 대응 |
|---|---|
| 계란 익히기 (단백질 변성) | 고데기 열 손상 — 익은 머리는 안 돌아온다 |
| 발효·산도 | 샴푸 pH, 산성 트리트먼트의 원리 |
| 재료 손질·숙성 | 전처리·중간처리의 이유 |
| 레시피 계량 | 성분 배합비, 과유불급(단백질 오버) |

### 운동·헬스 → 루틴, 그리고 "모발은 근육이 아니다"
| 원개념 | 트리필드 대응 | 주의 |
|---|---|---|
| 운동 루틴·습관 | 홈케어 루틴 설계 | |
| 근육 회복·초과회복 | **역치환**: 모발은 죽은 조직이라 회복이 없다 | 이 반전 자체가 콘텐츠가 된다 |
| 단백질 보충제 | 단백질 트리트먼트 (역시 과하면 부러진다) | |

### 심리·자기계발 → 습관과 오해
| 원개념 | 트리필드 대응 |
|---|---|
| 작은 습관의 힘 | 물기 털기·낮은 온도·브러싱 순서 같은 미시 습관 |
| 통념 깨기 프레임 | 미신 팩트체크 필라(PIL-5) 직결 |

### 패션·뷰티 → 경계 주의 (살롱 이관 1순위)
스타일·트렌드가 중심이면 **살롱으로 이관**. 트리필드로 틀려면 반드시 "소재(모발)의 관점"으로 내려간다.
예: "올여름 유행 컬러" → (살롱) / "그 컬러가 8레벨 탈색을 요구하는 화학적 이유" → (트리필드 가능)

### IT·테크 → 시스템 비유
| 원개념 | 트리필드 대응 |
|---|---|
| 보안·방화벽 | 큐티클 = 모발의 보안 시스템 |
| 배터리 수명·최적화 | 모발 수명 관리, 열 스로틀링=온도 관리 |
| 백업 없음 경고 | 모발은 백업이 없다 (비가역성) |

사전에 없는 업종이 오면: ① 레퍼런스의 정보 골격을 먼저 뽑고 ② "이 구조와 같은 모양의 모발 현상이 있나?"를 PIL-1~5에서 탐색 ③ 없으면 반려(§4).

## 2. 4단계 치환 절차

```
STEP 1  골격 추출     dna에서 [후킹공식 / 카드시퀀스 / 정보밀도 / 강조리듬] 4요소 추출
STEP 2  도메인 라우팅  §1 사전으로 개념 매핑 → 트리필드 토픽 후보 3개 생성
STEP 3  각도 검증     후보마다 경계 판정: "중심 질문이 '머리카락에서 무슨 일이 일어나는가'인가?"
                     + 필라 배정(PIL-1~5) + 페르소나 매칭(T-P1~3) → 탈락 시 이관/폐기 사유 기록
STEP 4  키치 입히기   생존 후보에 훅 타입(H1~H6) 배정, fact_basis 후보(근거 팩트 3개+) 조사·기록
                     → cardnews_plan.json 골격 생성 (카피는 아직 비움)
```

- 각 STEP은 독립 재실행 가능해야 한다 (00 원칙). STEP 산출물은 `cardnews/plans/{plan_id}/`에 단계별 저장.
- STEP 4의 fact_basis가 3개 미만이면 **여기서 멈춘다** — 팩트 없는 키치는 낚시다 (01 §4).

## 3. 치환 실전 예시 (worked example)

### 예시 A — 경제 레퍼런스
**원본**: "복리의 마법 — 월 10만원이 10년 뒤 얼마가 될까" (8장: 충격숫자 표지 → 개념 → 계산 3연속 → 반전 → 요약 → CTA)

| 골격 요소 | 원본 | 트리필드 치환 |
|---|---|---|
| 훅 공식 | 충격 숫자 | H3 비유 치환: "당신의 머리는 지금 복리로 망가지는 중" |
| 시퀀스 | 개념→계산 반복→반전 | WHY→FACT 3연속(하루 1회 고데기 = 연간 365회 열충격, 60℃부터 단백질 변성 시작, 시스틴 결합은 복구 불가)→MYTH(트리트먼트로 복구된다? 보수일 뿐)→RECAP→CTA |
| 정보 밀도 | 카드당 숫자 1개 | 동일하게 카드당 수치 1개 |
| 강조 리듬 | 6번째 카드 반전 | 6번째 카드에 MYTH 배치 |

→ 토픽: **"열 손상 복리설 — 매일의 고데기가 1년 뒤 만드는 것"** (PIL-3, T-P1·T-P3)

### 예시 B — 요리 레퍼런스
**원본**: "계란 완숙·반숙 온도의 과학" (6장)
→ 단백질 변성 구조 그대로 이식. 토픽: **"고데기 180℃, 머리카락은 이미 완숙입니다"** (PIL-3, H1 충격 팩트: "케라틴은 60℃부터 익기 시작"). 시퀀스 6장 유지: cover + point 4 + cta.

### 예시 C — 반려 케이스
**원본**: "요즘 뜨는 상권 TOP5" (부동산)
→ STEP 3 탈락: 어떤 매핑을 써도 중심 질문이 '운영/입지'가 됨 → **아카데미 이관** (`handoff: academy` 기록). 트리필드 버전 없음.

## 4. 반려·이관 규칙

| 조건 | 처리 | 기록 |
|---|---|---|
| 중심이 심미·스타일 | 살롱 이관 | `handoff: salon` + 사유 |
| 중심이 운영·매출·마케팅 | 아카데미 이관 | `handoff: academy` + 사유 |
| 모발로 틀면 의학(탈모 치료 등)이 됨 | 폐기 | `rejected: medical` |
| fact_basis 3개 확보 실패 | 보류 | `hold: insufficient_facts` (예진 매니저에게 소스 요청) |
| 같은 레퍼런스 3회째 사용 | 마지막 사용 후 `cardnews/references/retired/`로 이동 | 00 규칙 |

## 5. 출력 규격 (STEP 4 산출물)

`cardnews/plans/{plan_id}.json` — 03 공통 스키마를 따르되 트리필드 필수 필드:

```jsonc
{
  "brand": "trifield",
  "source_ref": "cardnews/references/dna/2026-08-ref-012.json",
  "topic": "열 손상 복리설 — 매일의 고데기가 1년 뒤 만드는 것",
  "pillar": "PIL-3",
  "personas": ["T-P1", "T-P3"],
  "hook_type": "H3",
  "card_count": 7,                     // 3~8 (cards.ts 제약)
  "sequence": ["HOOK","FACT","WHY","MYTH","HOW","RECAP","CTA"],
  "fact_basis": [                      // 최소 3개, 없으면 이 파일을 만들 수 없음
    "케라틴 단백질은 약 60℃부터 변성 시작 (습윤모는 더 낮음)",
    "시스틴(이황화) 결합은 절단 시 자연 복원되지 않음",
    "모간(hair shaft)은 죽은 조직 — 생물학적 회복 메커니즘 없음"
  ],
  "stolen_rhythm": {                   // P1: 훔친 것은 구조뿐임을 명시
    "hook_formula": "충격 숫자 선제시",
    "density": "카드당 수치 1개",
    "emphasis_at": 6
  },
  "design_note": "강조색은 FACT 카드 숫자에만"   // 토큰 역할명만 (P3)
}
```

## 6. 해부·치환 실적 (실제 레퍼런스)

### ref-001 — 경제·시사 밈뉴스 커버 (2026-08-19, 대표 제공)

DNA: `cardnews/references/dna/trifield/trifield-ref-001-meme-news-cover.json`

**훔친 것 (P1 통과분):**

| 요소 | 원본 | 트리필드 전용 |
|---|---|---|
| 커버 4요소 구조 | 실사 배경 + 컷아웃 + 말풍선 + 헤드라인 2~3줄 | 동일 구조. 배경=시술현장·현미경 사진, 컷아웃=머리카락·모낭·고데기·계란 등 의인화 대상 |
| 낙차 병렬 배치 | 헤드라인(팩트) ↔ 말풍선(유머)이 한 장에 동시 | 헤드라인=모발 과학 팩트, 말풍선=당사자(모발·성분)의 1인칭 대사 — H4의 시각 구현 |
| 증거 위젯 | 주가창 스크린샷 무편집 삽입 | **과학 증거 위젯**: 온도 표시, pH 미터, 성분표, 전자현미경 컷. fact_basis를 '보여주는' 장치 |
| 근황체 | "MSCI 8월 포폴 근황:" | "탈색 3번 한 시스틴 결합 근황:" — 훅 H7로 등재 |
| 음슴체+슬랭 어미 | "~함 ㅎ", "~드림", "ㅋㅋ" | 커버·포인트 제목에 허용 (01 §4 개정) |
| 정보 밀도 | 커버 1장 = 팩트 1 + 유머 1 | 동일. 2팩트 금지 |

**버린 것:** 흰 고딕+검정 테두리 자막, 말풍선 모양·컬러, 로고 배치, 사진 톤 → 전부 토큰으로 치환 대기.

**렌더러 갭 (실장 확인 필요):** 현 `cards.ts` cover는 `title`뿐. `bubble`(말풍선 대사)·`evidence`(증거 위젯 지정)·`cutout`(컷아웃 소재 지시) 슬롯이 렌더러에 없다. plan JSON에는 지금부터 실어두고(하위호환 — 렌더러가 무시), 04 토큰 스키마에 역할 `말풍선서체`·`증거위젯틀` 추가를 요청한다.
